# Bulk Repository Update

Скрипт для массового обновления всех Git-репозиториев в директории:
находит каждый `.git`, делает `fetch`, сбрасывает рабочую копию к
`origin/<текущая\_ветка>` и вычищает неотслеживаемые файлы.

Полезен, когда у вас десятки клонов в одной папке (монорепа, набор
сервисов, тестовые окружения) и нужно быстро привести их к состоянию
«как на сервере».

\---

## ⚠️ Важно

Скрипт **разрушительный**. Он выполняет:

* `git reset --hard origin/<branch>` — локальные коммиты будут потеряны;
* `git clean -fd` — неотслеживаемые файлы и папки будут **удалены**.

Не запускайте его в директориях, где есть незакоммиченная работа, если
не уверены, что она вам не нужна. Сделайте бэкап или сначала запустите
скрипт в режиме `--dry-run` (см. ниже).

\---

## Возможности

* Рекурсивный поиск всех `.git` в `$PWD` (включая вложенные).
* `fetch --prune origin` перед любыми изменениями.
* Пропуск репозитория, если `fetch` завершился ошибкой — **никакого
сброса к устаревшему `origin`**.
* Корректная обработка `detached HEAD` (отдельно от «пустой ветки»).
* Проверка, что `origin/<branch>` действительно существует.
* Пропуск сабмодулей.
* Безопасная обработка имён файлов и директорий с пробелами и `\\n`.

\---

## Требования

* `bash` 4+
* `git` 2.x
* Unix-подобная ОС (Linux, macOS, WSL)
